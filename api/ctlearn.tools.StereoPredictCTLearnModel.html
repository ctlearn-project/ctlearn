StereoPredictCTLearnModel#

class ctlearn.tools.StereoPredictCTLearnModel(*args: t.Any, **kwargs: t.Any)[source]#

Bases: PredictCTLearnModel

Tool to predict the gammaness, energy and arrival direction from R1/DL1 stereoscopic data using CTLearn models.

This tool extends the PredictCTLearnModel to specifically handle stereoscopic R1/DL1 data. The prediction is performed using the CTLearn models. The data is stored in the output file following the ctapipe DL2 data format. It also stores the telescope/subarray pointing monitoring and DL1 feature vectors (if selected) in the output file. By default, waveforms and images are not copied to the DL2 output file unless explicitly enabled in the configuration.
