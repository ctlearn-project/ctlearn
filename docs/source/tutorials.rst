Public CTAO data exploration
============================

This tutorial follows the executable Python-script style used by ctapipe's
tutorials. It downloads a small SimTel sample for the monoscopic examples and
four CTAO simulation files from `Zenodo record 7298569
<https://zenodo.org/records/7298569>`_ for the stereo example. The four Zenodo
files require about 3.5 GB of disk space. Downloaded and converted files are
reused on subsequent runs. By default, data are stored under
``~/.cache/ctlearn/tutorial-data``; set ``CTLEARN_TUTORIAL_DATA_DIR`` to use a
different directory. The CI workflow preloads the source files, caches the
converted products, and limits processing to 1000 events per input file to keep
the documentation build bounded. Running the tutorial locally without that
environment variable processes the full files. The CI build executes the
tutorial and embeds its output; successful builds from pushes to ``main`` are
deployed to GitHub Pages.

To run the complete tutorial locally from the CTLearn repository root, install
CTLearn with its development dependencies and execute:

.. code-block:: console

   python examples/tutorials/explore_public_data.py

Training a CTLearn model
========================

The training tutorial documents monoscopic energy and direction regression,
gamma/proton classification, custom ``SingleCNN`` and ``ResNet`` architectures,
transfer learning with ``LoadedModel``, stereo image stacking, and waveform
training. It uses only the converted gamma-ray and proton ``00`` files for the
image examples and leaves the ``01`` files untouched for later evaluation.
The three example JSON configs are copied into
``docs/source/config``. The tutorial uses the descriptions
from the training notebook and executes every example sequentially during
the documentation build. This requires working TensorFlow and PyTorch
installations and can take substantial time and compute resources.
Run the data exploration tutorial first, then execute the training tutorial
from the repository root:

.. code-block:: console

   python examples/tutorials/train_ctlearn_model.py

The script presents each example as its own explanation followed by a literal
``ctlearn-train-keras-model`` command and then its PyTorch equivalent,
``ctlearn-train-pytorch-model``. The commands run in order; each
transfer-learning command uses the ``SingleCNN`` checkpoint from the same
framework's preceding architecture example. To use a different cache or output
location, set ``CTLEARN_TUTORIAL_DATA_DIR`` or
``CTLEARN_TUTORIAL_OUTPUT_DIR``. Training output defaults to
``~/.cache/ctlearn/tutorial-training``; use a new output directory for each
run because existing Keras and PyTorch model output directories are not
overwritten.

To run classification directly in a terminal, set ``TRAIN_DIR`` to the
converted cache directory printed by the data exploration tutorial:

.. code-block:: console

   TRAIN_DIR="$HOME/.cache/ctlearn/tutorial-data/ctapipe-<ctapipe-version>"
   ctlearn-train-keras-model \
       --signal "$TRAIN_DIR" \
       --pattern-signal "gamma-diffuse_with_images_00.dl2.h5" \
       --background "$TRAIN_DIR" \
       --pattern-background "proton_with_images_00.dl2.h5" \
       --output "$HOME/.cache/ctlearn/tutorial-training/keras-classification" \
       --config docs/source/config/dl1dh_example_config.json \
       --config docs/source/config/ctlearn_train_model_example_config.json \
       --reco type \
       --DLImageReader.focal_length_choice EQUIVALENT \
       --TrainCTLearnModel.n_epochs 5 \
       --TrainCTLearnModel.batch_size 32

   # PyTorch equivalent: use the same arguments with the PyTorch command and output directory.
   ctlearn-train-pytorch-model \
       --signal "$TRAIN_DIR" \
       --pattern-signal "gamma-diffuse_with_images_00.dl2.h5" \
       --background "$TRAIN_DIR" \
       --pattern-background "proton_with_images_00.dl2.h5" \
       --output "$HOME/.cache/ctlearn/tutorial-training/pytorch-classification" \
       --config docs/source/config/dl1dh_example_config.json \
       --config docs/source/config/ctlearn_train_model_example_config.json \
       --reco type \
       --DLImageReader.focal_length_choice EQUIVALENT \
       --TrainCTLearnModel.n_epochs 5 \
       --TrainCTLearnModel.batch_size 32

In a Jupyter notebook, prefix the same command with ``!``. For the other
examples, run the script to execute the commands in sequence. Start
TensorBoard for the resulting metrics with
``tensorboard --logdir ~/.cache/ctlearn/tutorial-training/``.
