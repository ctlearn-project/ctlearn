With ``conv_backend="hexagdly"``, ``kernel_size`` and the pooling size are now read as a square-kernel width, like for the square backend, instead of a number of hexagonal rings. The same configuration therefore describes comparable models on both grids: a ``kernel_size`` of 3 is the 7-cell hexagon and 1 is a plain 1x1, which also makes the hardcoded ``kernel_size=1`` projections of the ResNet true 1x1 convolutions. A hexagonal model built from a configuration now has smaller kernels than before, so it must be trained again; models saved with an earlier version still load unchanged. Requires ``keras-hexagdly>=0.6.0`` and ``pytorch-hexagdly>=0.4.0``.
